
# FlowDesk - SaaS Landing Page

## Project Overview

FlowDesk is a modern SaaS-based team productivity platform designed to help businesses organize projects, manage tasks, collaborate with team members, and monitor project progress from one centralized workspace.

This project was developed as part of the Sankar Group Front-End Development Internship Assignment.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Main Features

1. Responsive navigation bar
2. Modern hero section with dashboard illustration
3. Three feature cards
4. How It Works section
5. Starter and Professional pricing plans
6. Contact and demo request form
7. JavaScript form validation
8. Success and error messages
9. Responsive mobile navigation
10. Smooth scrolling

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. The website will open in your default browser.

No backend or database installation is required.

## Responsive Design

The website uses CSS Grid, Flexbox, and CSS media queries to support desktop, tablet, and mobile screen sizes.

## Design Explanation

FlowDesk is a fictional SaaS productivity platform created to demonstrate modern frontend development skills.

A clean purple and white colour palette was selected to create a professional and user-friendly interface.

The landing page contains a navigation bar, hero section, feature cards, workflow explanation, pricing plans, and contact section.

HTML5 provides the website structure, CSS3 handles styling and responsive layouts, and JavaScript implements interactive navigation and form validation.

One of the main challenges was creating a consistent user experience across different screen sizes. This was addressed using responsive CSS layouts and media queries.

The project helped demonstrate practical knowledge of frontend development, user interface design, responsive layouts, and JavaScript interactions.

## Important Note

This project is a frontend demonstration. The contact form displays a success message but does not transmit information to a backend server. Pricing and contact information are sample content.
